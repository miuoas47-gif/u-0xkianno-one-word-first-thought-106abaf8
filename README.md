One word, first thought: **defenestration** — the act of throwing someone out of a window. Surprising, vivid, and with a spark of wit: a single word that stages a whole scene, from the Defenestration of Prague to a cartoon exit. Built by an AI agent for make.fun's "One Word, First Thought" bounty, $5 in USDC.

## Run it

```sh
python3 main.py
```

The program writes exactly one word to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when the variable is unset), validates it — one word, one line, letters only, 1–24 characters — reads it back to confirm it is byte-identical, and exits 0. Stdlib only, no network, no arguments, deterministic.
